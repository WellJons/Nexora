# Nexora

Локальная игровая платформа для одиночных игр. Собственный дизайн, без подписки.

## Запуск на Windows

Установите Node.js LTS, затем в папке проекта выполните `npm install` и `npm start`.

Первая версия: каталог, обнаружение Steam, запуск установленных игр, избранное и резервные копии. Трейнеры пока не подключены; карточки функций показывают планируемые возможности, а не действующие модификации.

Обложки загружаются из публичного CDN Steam; без сети используются цветные заглушки. Nexora не связан со Steam или WeMod.
