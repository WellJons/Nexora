# Nexora

Локальная игровая платформа для одиночных игр. Без подписки и регистрации.

## Запуск на Windows

Установите Node.js LTS, скачайте или клонируйте репозиторий. В папке проекта выполните:

```powershell
npm install
npm start
```

`npm test` запускает тесты ядра. `start.cmd` устанавливает зависимости при первом запуске.

Версия 0.1: каталог, обнаружение Steam, добавление EXE, запуск игр, избранное, история, резервное копирование папок сохранений. Трейнеры пока не подключены: функции на экране являются планом, отключены и не изменяют игру. Обложки загружаются из публичного CDN Steam; без сети есть заглушки. Nexora не связан со Steam или WeMod. Для собственного использования в одиночных играх.

## 0.2 · Mod discovery

Раздел «Моды» подключает публичный API Modrinth для Minecraft: поиск, фильтры версии и загрузчика, выбор релиза и JAR-файла. Файл сохраняется только после проверки размера и SHA-512; существующие файлы не перезаписываются. Загрузки сохраняются в локальной истории. Проверка целостности не является проверкой на вредоносный код. Установка, зависимости и обновления выполняются вручную. Никаких файлов модов Nexora не хостит. Для поиска необходим интернет.

См. [дорожную карту](docs/ROADMAP.md).

## 0.3 · Mod Manager

В «Загрузках» выберите «Установить», затем существующую папку `mods` нужного профиля Minecraft. Только JAR-файлы, ранее скачанные через Nexora и повторно проверенные по SHA-512; файлы не перезаписываются. В «Мои моды» можно отключать/включать установленные Nexora файлы и открывать папку. Отключение создаёт имя `.jar.nexora-disabled`, включение возвращает исходное. Для этого нужна файловая система с поддержкой жёстких ссылок (например, NTFS). Закройте игру, вручную проверьте загрузчик, версию и зависимости. Автоматическое разрешение конфликтов, установка зависимостей, сканирование чужих модов и обновление пока отсутствуют. SHA-512 не является антивирусной проверкой.

## 0.4 · Performance и сборка Windows

В разделе «Мониторинг» показываются фактические CPU, RAM и доступные данные GPU; история хранится в памяти окна. Датчики, которые драйвер не предоставляет, отображаются прочерком; FPS пока нет. Мониторинг использует локальную библиотеку, не собирает серийные номера и не отправляет данные на сервер.

Готовый Windows x64 пакет создаётся через `npm run package:win` (Node.js 22.12+; рекомендуется 24 LTS). В GitHub Actions после тестов формируется `Nexora-Windows-x64`. Распакуйте целиком и откройте `Nexora.exe`; Node.js для собранного приложения не нужен. Это неподписанная alpha-сборка, не установщик. Лицензии зависимостей сохраняются в пакете.

## 0.5 · Game workspace

Обнаружение установленных Epic Games по локальным манифестам и запуск через официальный клиент; игры без корректного EXE пропускаются. В «Мои профили» — заметки, чек-листы и история команд запуска (не игровое время). В «Трейнеры» подключаются уже установленные Cheat Engine или отдельный Apprentice, можно сохранить ссылки на локальные CT-файлы и открыть их через Cheat Engine после явного подтверждения. Nexora не анализирует, не исполняет и не изменяет CT самостоятельно. Встроенный движок ещё не готов. Только одиночные игры без античита.

Сборка Windows использует отдельную staging-папку и явно включает runtime-зависимость мониторинга.

## 0.6 · Save Vault

Новые копии получают SHA-256 манифест содержимого, количество и объём файлов. Извлечение создаёт отдельную папку и ничего не перезаписывает. Восстановление в исходную папку доступно для новых копий: сначала проверяется содержимое, затем текущая папка сохраняется в соседнем каталоге `.nexora-restore-*/previous`, после чего копия занимает исходный путь. Предыдущие файлы остаются на диске и доступны в списке. Старые копии можно только извлекать. Закройте игру и приостановите облачную синхронизацию; операция рассчитана на обычные локальные папки, не ссылки и не корневые каталоги. При сбое между переименованиями предыдущие файлы остаются в соседней папке. До завершения проверки не удаляйте её.

## 0.7 · Встроенный движок Nexora

Новый экран «Трейнеры» заменяет запуск внешних инструментов. Готовая Windows x64 сборка содержит собственный нативный модуль и не требует Cheat Engine, .NET SDK или других установок. При разработке из исходников необходимо один раз выполнить `npm run trainer:build` с .NET 10 SDK перед запуском/упаковкой.

Для одиночной игры: запустите её, выберите в Nexora, найдите процесс, выполните первый поиск Int32 или Float32, измените значение обычным способом в игре, уточните поиск, выберите найденный адрес и задайте новое значение. Сканируются только выровненные 32-битные значения в приватных областях памяти с правом чтения и записи; лимит 512 МиБ и 50 000 совпадений, результаты могут быть неполными. Движок не обходит ограничения Windows, античит или защиту. Нет инъекций, патчей кода, заморозки, готовых игровых пресетов и импорта CT. Старые настройки внешних инструментов больше не используются. Операции потенциально могут нарушить состояние игры; используйте резервные копии и только разрешённые одиночные игры.

## 0.8 · Session Trainer и новая библиотека

Главный экран получил игровую витрину, быстрый доступ к модулям, реальные счётчики коллекции и недавние игры. В библиотеке есть фильтры по источнику и сортировка.

В редакторе значений можно выбрать найденный адрес, дать ему имя и добавить в сессионный трейнер (до 12 параметров). Параметры можно менять и явно замораживать на срок до пяти минут; заморозка прекращается по запросу, при потере доступа к адресу и закрытии сессии. Она не восстанавливает автоматически исходное значение и может вызвать нестабильность игры. Адреса сбрасываются при завершении сессии, не сохраняются между запусками; нет готовых совместимых игровых пресетов. Только для разрешённых одиночных игр без античита.

## 0.9 · HUD и GOG

В «Мониторинге» можно включить компактный HUD, выбрать угол экрана и скрыть/показать его комбинацией Ctrl+Shift+F10 (если свободна). Панель использует обычное прозрачное окно Windows поверх окон, без внедрения в игру. Поддержка эксклюзивного полноэкранного режима не гарантируется; FPS не измеряется. При закрытии Nexora панель и сочетание клавиш освобождаются. Показатели оборудования общесистемные. Игры GOG обнаруживаются по установленным локальным записям реестра с корректным EXE; Nexora не обходит требования запуска игры, не получает аккаунт и не скачивает игры.

## 0.10 · Mod Center

План установки Minecraft: укажите точную версию и загрузчик, выберите релиз/файл. Обязательные зависимости из Modrinth разрешаются рекурсивно (до 32 проектов/512 МиБ), точные версии проверяются, для неточных выбирается свежий стабильный релиз. План показывает файлы перед подтверждением; загрузки проверяются по SHA-512. Установка не перезаписывает существующие файлы, проверяет известные конфликтующие версии и при ошибке пытается удалить только свои новые проверенные файлы. Другие моды, фактическая конфигурация профиля, необъявленные конфликты и безопасность JAR не проверяются. В «Мои моды» доступна проверка новых стабильных релизов, без автоматической замены файлов. API требует интернет.

## 0.11 · Thunderstore и гайды

В Mod Center появился второй каталог: Thunderstore для Valheim, Lethal Company, Risk of Rain 2, R.E.P.O. и ULTRAKILL. Используется публичный community v1 API; поиск и сортировка выполняются по локальному кешу на 5 минут. Можно выбрать релиз и увидеть заявленные зависимости, сохранить ZIP без перезаписи. При загрузке проверяются размер и сигнатура, записывается локальный SHA-256 (не эталон автора). Автоустановка, проверка антивирусом и разрешение зависимостей для Thunderstore пока не реализованы. Minecraft по-прежнему использует отдельный путь Modrinth. «Гайды» — восемь оригинальных офлайн-справочников с поиском по тексту и фильтром игры. Интернет нужен для каталогов, не для гайдов.

## 0.12 · Nexora Translate

Автоматический OCR английского текста в выбранной прямоугольной части экрана, с русским переводом через MyMemory (анонимный лимит сервиса и локальный лимит 4500 символов за сессию) или DeepL с личным ключом. Только OCR работает офлайн. OCR использует один лениво создаваемый локальный CPU-воркер и встроенные языковые данные. Кадр захватывается с разрешением не выше 1920×1080, обрезается и сравнивается с предыдущим по хешу; при неизменной картинке OCR пропускается. Повторный текст кешируется в памяти. Интервалы 2,5/4/6 секунд после обработки, без параллельных запросов. Сессия останавливается через 30 минут или вручную; окно Nexora на переднем плане ставит захват на паузу. Скриншоты не передаются в сеть и не сохраняются, только распознанный текст передаётся выбранному сервису после подтверждения. Ключ не сохраняется на диск. Alt+Shift+T останавливает сессию, если сочетание свободно. Используйте окно/безрамочный режим; точность, задержка и нагрузка зависят от игры, шрифта, оборудования и сети. Не захватывайте персональные данные. Поддержка других языков и полностью офлайн-перевод не реализованы.

## 0.13 · Перевод всего игрового окна

Основной режим — выбор запущенного окна: OCR распознаёт английские блоки по всей поверхности окна, до 24 блоков за кадр, перевод накладывается в соответствующих позициях. До 5 новых онлайн-фраз за цикл; неизменные фразы кешируются (до 512). Окно и PID проверяются встроенным компонентом Windows, фоновый режим приостанавливается; при переключении оверлей скрывается. Прежний режим выделенной области оставлен как экономный. Требуется оконный/безрамочный режим, некоторые игры не позволяют захват; возможны погрешности расположения текста, распознавания и времени перевода. Полностью автономный перевод пока отсутствует, OCR локальный. Нагрузка и качество в играх не измерены.

## 0.14 · Offline Translate

По умолчанию выбран локальный перевод английский → русский. Встроенный интерфейс один раз загружает квантованные веса и токенизатор (около 250 МБ) в каталог данных приложения; SHA-256 обоих ONNX-файлов сверяется с опубликованными хешами, после загрузки запускается тест локального перевода. Дальше сеть при инференсе отключена (`allowRemoteModels=false`, `local_files_only=true`), CPU, два вычислительных потока ONNX, отдельный воркер, без обращения к API перевода. Модель создаётся лениво, воркер завершает работу при остановке сессии. Целое выбранное окно можно переводить без ограничения длительности; прежние сетевые и экранные режимы сохраняют прежние лимиты. Модель не содержит игровых текстов заранее: качество зависит от OCR и контекста. Реальная задержка, потребление памяти и FPS требуют проверки на игровых ПК. Тест реального скачивания и перевода доступен через workflow_dispatch или push с маркером [local-model-test] в сообщении коммита (группа local-model-smoke).

## 0.15 · Translation profiles

Лёгкий (q8, до 2 потоков, 5 новых блоков), Баланс (q8, до 4 потоков, 8 новых блоков) и Полное качество (FP32, до 6 потоков, 10 новых блоков, до 40 блоков OCR, захват целого окна до 2560×1440, больше текста на блок). ONNX использует CPU, резервирует два логических процессора при возможности. Пакеты устанавливаются отдельно, лёгкий и баланс используют одну модель. Полные веса OPUS-MT — те же обученные параметры без квантования, не гарантируют значительного прироста точности. Проверка сравнивает работоспособность обоих пакетов на игровых фразах; не является независимым бенчмарком качества или FPS.

## 0.16 · Advanced

Добавлен независимый профиль M2M100-418M (квантованные ONNX-веса около 632 МБ плюс токенизатор, CPU до 6 потоков). Переводчик явно передаёт en → ru. Установка отдельная, с проверкой SHA-256 и пробным переводом. OCR пока английский. M2M100 — альтернативная архитектура, а не доказанное улучшение EN→RU; качество и скорость сравниваются на игровых фразах. Для экспериментального FP32 отключена оптимизация графа ONNX в попытке устранить ошибку Slice в декодере; требуется повторный тест. Если установка не проходит пробный перевод, пакет не активируется. Профили Lite и Balanced сохраняют прежний пакет.

## 0.17 · Windows installer

Готовый установщик `Nexora-Setup-0.17.0-x64.exe` и SHA-256 создаются в `dist/installer` и публикуются в артефакте `Nexora-Setup-Windows-x64`. Inno Setup 6.7.1 (сборка, не дополнительная установка для пользователя), тёмный мастер, фирменный логотип, папка на выбор, ярлыки и запуск. Windows 10/11 x64, установка для текущего пользователя. Portable-архив сохраняется отдельно. Установщик пока не подписан.

Удаление через «Установленные приложения»: закройте Nexora. Удаляются установленные файлы, языковые пакеты и известные служебные папки/настройки текущего пользователя. Моды и скачанные архивы вне служебных каталогов, игры, реальные сохранения и внешние резервные копии не удаляются. Внутренние копии Save Vault и отдельный индекс сохраняются в `%APPDATA%\Nexora` по умолчанию; интерактивно можно выбрать удаление и внутренних копий, без удаления оригиналов. Известные пользовательские пути защищены даже внутри служебных папок; неизвестные файлы и ссылки не удаляются намеренно. При повреждённом индексе или занятых файлах очистка может завершиться частично/не выполняться с предупреждением. Новые временные файлы загрузок находятся в `scratch`; старые оставшиеся временные файлы прежних версий не удаляются автоматически. В CI предусмотрен тест установки и удаления с проверкой сохранности модов и бэкапов.

## 0.18 · Игровой режим

Выберите реально запущенный процесс установленной игры. Nexora фиксирует длительность и каждые 5 секунд берёт системные показатели CPU/GPU/RAM; отображаются средние по доступным показаниям последних 720 замеров, не FPS и не нагрузка конкретной игры. История сохраняет до 1000 завершённых сессий. Дополнительно можно явно разрешить смену приоритета только Normal → Above Normal на срок до 30 минут (без системных твиков и остановки процессов). Приоритет возвращается при штатной остановке или истечении лимита, если не был изменён извне. При аварии/принудительном уничтожении helper он может остаться до завершения процесса; FPS не гарантируется. Запись начинается после подключения, не учитывает запуск до него, а при сбое может закончиться последним измеренным временем. Исправлена генерация SHA-256 установщика без зависимости от Get-FileHash.

## 0.19 · BepInEx plugins

Thunderstore ZIP можно установить из «Загрузки» в существующую BepInEx-папку. Архив повторно проверяется по локальному SHA-256 и размеру, защищённая распаковка ограничивает количество файлов, размер и пути; обычные DLL-плагины помещаются в `BepInEx/plugins/Nexora-managed/<package>`. Отключение перемещает каталог в `BepInEx/Nexora-disabled/<package>` без перезаписи. Загрузчики, patchers, сложные раскладки, исполняемые установщики не устанавливаются. Зависимости и совместимость проверяет пользователь. Установка не запускает мод, но код DLL будет выполняться игрой при загрузке; проверка архива не заменяет проверку безопасности. Моды сохраняются при удалении Nexora. Реальные игры ещё требуют проверки.

## 0.20 · Подготовка к первому тестированию

В настройках доступна проверка опубликованных GitHub Releases с подходящим Windows-установщиком и файлом SHA-256. Самостоятельный запуск, скачивание и установка обновлений не выполняются; ссылка открывает официальный релиз. До публикации релиза проверка покажет отсутствие готового выпуска. В переводчике можно удалить выбранный языковой пакет без удаления других моделей; неизвестные файлы сохраняются, известные пользовательские пути блокируют операцию. CI запускает собранный Electron с изолированным временным профилем, проверяет наличие и отрисовку 14 разделов и IPC библиотеки, после чего выполняет существующий тест установщика. Это базовый smoke-тест, а не проверка всех функций в играх.

## 0.21 · Персональные шаблоны трейнеров

Для выбранной игры можно сохранить именованный числовой шаблон (тип, желаемое значение и комментарий) и подготовить параметры в редакторе при следующем запуске. Шаблоны не сохраняют адреса памяти, ничего не записывают автоматически и не являются проверенными готовыми трейнерами. Повторный поиск в запущенной одиночной игре требуется. Исправлено сравнение канонических Windows-путей при удалении моделей.

## 0.22 · Midnight Violet 2.0

Переработаны навигация, векторные иконки, заголовок окна с нативными кнопками Windows, карточки, кнопки, поля и цветовая система; переходы страниц, hover и уведомления используют короткие анимации. Настройка «Анимации» сохраняется локально, системный prefers-reduced-motion учитывается. Постоянных фоновых анимаций нет. Мастер Inno Setup получил фирменную страницу возможностей и обновлённую графику; удаление использует тёмный стиль и пояснение сохранности игровых файлов. В 0.22 добавлены также фирменные окна подтверждения с фокусом на отмене, Escape и отменой при закрытии; нативный выбор файлов сохранён. Тест интерфейса открывает тестовый диалог и проверяет отмену. Удаление программы предлагает явно сохранить или удалить внутренние бэкапы, для удаления требуется дополнительное подтверждение. Снимок тестового диалога попадает в артефакт превью при успешном запуске.

## 0.23 · Единый запуск игры

Кнопка «Играть» использует обычный запуск Steam/Epic/GOG или локального EXE, предварительно проверяя процессы по пути выбранной игры. Если игра уже запущена, повторный запуск не производится. После команды запуска Nexora до 90 секунд проверяет наличие процесса, с возможностью отменить ожидание (не завершает игру). В панели запуска можно перейти в редактор с найденными PID. Для изменения памяти по-прежнему требуется явно подтвердить одиночную игру и начать сессию; адреса не переиспользуются, ничего автоматически не изменяется. Лаунчеры или несколько процессов могут потребовать выбора вручную. Моды загружаются самим Minecraft-профилем (версия/загрузчик должны совпадать) или установленным BepInEx при запуске игры; Nexora не устанавливает загрузчик и не запускает сетевые читы. Для первого теста используйте готовый установщик из успешного CI, а не исходники. Проверьте сканирование библиотеки, запуск игры, подключение редактора после загрузки сохранения, перевод и отключение/включение тестового доверенного мода.

Порядок первого тестирования: [docs/FIRST-TEST.md](docs/FIRST-TEST.md). Перед подключением трейнер повторно обнаруживает процессы выбранной игры; отменённые запросы не должны подменять выбор другой игры.

## 0.25 · Обновления и игровые команды

Проверка официальных GitHub Releases выполняется при запуске (отключается в настройках). Опциональная автозагрузка (выключена по умолчанию) и кнопка «Обновить» загружают установщик, проверяет размер и SHA-256, затем «Установить обновление» запускает мастер после подтверждения. Без цифровой подписи SHA-256 не является независимым доказательством авторства. Портативные копии обновляются вручную. Установщик обновляет программу, модели и пользовательские данные сохраняются; временные загрузки находятся в каталоге updates и удаляются при штатном удалении. Публикация alpha выполняется после успешной сборки по явному маркеру коммита. Добавлены штатные команды Skyrim, Fallout 4 и Minecraft Java: копируются в буфер обмена, вводятся в консоль самим игроком. Это не автоматические memory-трейнеры; в реальных играх ещё не проверены. Источники синтаксиса: https://steamcommunity.com/sharedfiles/filedetails/?id=680170618 ; https://fallout.fandom.com/wiki/Fallout_4_console_commands ; https://minecraft.wiki/w/Commands/effect ; https://minecraft.wiki/w/Commands .

## 0.27 · Независимая база игровых профилей

Каталог игровых функций и предметов находится в `data/game-profiles.json` (версионированная схема 1). Steam/Epic/GOG могут обнаруживать установленные игры независимо от поддержки трейнера. Профили сопоставляются по Steam ID, для остальных источников — по однозначному названию. Проверка каталога при старте и кнопка в настройках обращаются только к фиксированному HTTPS-адресу репозитория, скачивают ограниченный JSON, проверяют схему, допустимые команды и идентификаторы, используют более новую ревизию, сохраняют кэш. Приложение не загружает скрипты и не исполняет удалённый код. Автоматизация возможна только для уже реализованных адаптеров; неизвестный движок требует отдельной разработки. Для Bethesda ввод F8 остаётся ограничен двумя известными играми, Minecraft RCON — локальным сервером. Расширение профилей не требует пересборки UI. Новые игровые функции требуют проверки в реальной игре. Три существующих профиля и 73 предмета перенесены без расширения покрытия.

## 0.31 · Trainer Finder

При «Играть» параллельно синхронизируются проверяемые JSON-профили Nexora, автоматически открывается страница обнаруженной игры после появления процесса. Если профиль не найден, индекс публичного GitHub-репозитория sugirukun/Cheat-Engine-Tables (GPL-3.0) ищется по точному нормализованному названию папки игры. Только метаданные и ссылка на источник, без скачивания CT/EXE, без исполнения Lua/ASM, без заявлений о совместимости. Индекс кэшируется 6 часов, ограничены размер/таймаут, ошибки не блокируют запуск. Настройка отключает автоматический сетевой поиск и переход. Готовые встроенные адаптеры (например GK2) по-прежнему требуют явного подключения перед изменением значений. Отдельный ИИ не нужен. Это автоматизация поиска и подготовки, не универсальное исполнение внешних трейнеров.

Исправлена нормализация товарных знаков до Unicode NFKC, а также порядок автоматического открытия страницы после завершения запроса запуска. Индекс названий не определяет совместимость файлов.

## 0.32 · Launch-to-trainer

При запуске игры с включённым автоподбором Nexora автоматически подготавливает найденный профиль. Для встроенного GK2-адаптера подключение начинается после обнаружения процесса, повторяется при отсутствии сохранения (до пяти попыток с паузой 18 секунд) и отменяется пользователем. Начальное подключение только читает; запись лишь после явного действия. Остальные игры используют ранее реализованные адаптеры; внешние CT не исполняются. Добавлено чтение рюкзака GK2 и изменение количества одной однозначно найденной существующей стопки (1–999) с повторной проверкой текущего сохранения и количества. Новые предметы не создаются; названия из игровых ID, без гарантии русской локализации. Реальный игровой тест отсутствует. CI проверяет сценарии ожидания, отмены и неподдерживаемой игры.

0.32.1: рюкзак читается при успешном подключении, при невозможности — остаётся кнопка обновления. Интерфейс привязан к конкретной установке игры, не отображает ресурсы чужой сессии. Повторный запуск не подменяет уже активный трейнер. Проверка дублирующихся событий запуска и лимита попыток.

## 0.33 · CT preview download

Trainer Finder automatically downloads a single exact-title community CT candidate as bounded data (max 2 MiB), checks the expected byte size and Git blob SHA-1 from the index, previews up to 100 unique labels and reports the presence of script fields. Multiple candidates require choosing a preview. A digest verifies consistency with the source index, not trust or game compatibility. No external script, memory address, XML entity, binary or trainer is executed; no CT is written to disk or opened by the shell. In-memory preview cache. Existing GK2 live adapter remains independent. External trainer execution is not implemented.

0.33.1: for an automatically connected GK2 session, loss of the current save during a read-only status poll initiates a bounded reconnect to the original process. No prior freezes or values are restored. Process exit stops reconnect, and the global status lets the user cancel it. Actual game compatibility remains unverified. The stable test candidate 0.32.1 is already published.

## 0.34 · Adapter platform

Adapter registry describes supported implementations, capability modes, and exact profile identities. Remote data cannot register native code. Non-Steam aliases are matched as normalized exact titles rather than substrings. After launch, the GK2 adapter connects automatically; a previously configured local Minecraft RCON connection is verified automatically (no passwords saved or automatic writes). Console actions remain explicit. Unified save editor auto-discovers GK2 and Stardew Valley slots, uses a worker, allows manual file selection, exports separate verified copies without altering originals. Stardew XML adapter supports existing numeric money, stamina and health fields, including maxima if present, and updates corresponding SaveGameInfo scalars when present. Source: https://stardewvalleywiki.com/Saves ; https://www.wheresmysave.blog/stardew-valley-save-editor-money-name-farm/ . Only synthetic fixtures tested, no real game runtime. Diagnostics for selected game copies only version/build/profile/capabilities/status and helper availability, no file paths, raw errors, or credentials. Third-party CT execution remains unsupported.

GK2 inventory now exposes individual existing stacks with ephemeral opaque tokens from the latest inventory snapshot. Identity, player slot, current count and game state are rechecked before changing a selected stack. Stale selections refresh without writing. Optional offline ID-to-Russian name translation reuses the installed q8 model, caches up to 1200 labels in memory, limits jobs to 40 unique IDs, marks approximate translations. No item creation, external network translation, or game asset database is claimed. Actual runtime remains untested.

## 0.35 · External trainer execution

An installed game can bind one explicitly approved external EXE or a user-selected installed Cheat Engine executable plus a local CT file. Paths are selected in native dialogs, exact bytes pinned by SHA-256; no shell, custom arguments, automatic elevation, or execution of unapproved internet content. The built-in pinned catalog offers wizardice/GK2Trainer v1.1.1 for Steam 4358690 only (Apache-2.0, source link and published size/digest shown). After explicit approval, Play with auto-trainer enabled waits for the game process, downloads the pinned artifact if not cached, verifies size/SHA-256 and starts it in a separate window. Never claims cheats attached or working solely because a process started. The external window is controlled by its author; load your save and follow its instructions. User-selected CE may display script prompts; Nexora never answers them. Third-party source and binary safety/current build compatibility have not been independently established. No automatically enabling cheats. Local executable and CT changes require renewed consent. Unknown downloaded tables remain preview-only. Tests use synthetic files and fake process launch, not an actual trainer or game.

## 0.36 · Complete external-source flow

A found community table can be selected directly in Trainer Finder. Choose an already installed trusted Cheat Engine executable; Nexora obtains the exact CT bytes from the indexed repository, verifies size and Git blob digest, then asks for explicit consent showing separate SHA-256 hashes and the source. The approved data is cached under its SHA-256 and bound to the game. Future Play launches open the approved CT in the approved CE executable after the game starts; no auto-approval of CE scripts. User can revoke the binding; if content changes, renewed selection and consent are required. Game process is checked again after package preparation, before launch. This completes external process launch, not universal native in-app switches or game-specific compatibility. No arbitrary EXE discovered via web search is downloaded and executed. No real-game runtime has been tested.

## 0.37 · First-launch community trainer setup

Choose a trusted installed Cheat Engine once in Settings. The exact executable digest is stored locally. With auto-trainer enabled, a game with no automatic built-in adapter or approved binding searches the community catalog after process detection; only a single exact title match from a non-stale index is eligible for a first-use prompt. The user explicitly approves the exact CT and executable hashes. Nexora caches the table, rechecks the game process, and launches the approved engine with the CT. Multiple matches remain manual selection; decline does not retry. Known game profiles can also search community tables on demand. The Settings page lists and revokes saved bindings, including uninstalled games. No automatic script confirmations, elevated privileges, cheat activation, or universal game compatibility. The game keeps running on a missing or declined trainer. Tests are synthetic, not real-game verification.

## 0.38 · Catalog sources and external session lifecycle

The original bbfox0703/Mydev-Cheat-Engine-Tables repository is the primary indexed provider; the previous sugirukun fork is a fallback if the original index cannot be loaded. Source identity is retained for previews and verified downloads; cache format v2 includes provider identity. Exact title match remains required; no guessed game version compatibility. A running external trainer can be stopped after confirmation from the Nexora status bar. Only the child process started by Nexora is targeted; no game process or unrelated running process is closed. Stop does not guarantee restoring previously changed game values. This integrates with the 0.37 first-launch setup and shared CE approval, without automatic execution of unapproved files or scripts. Real-game testing still pending.
