# Nexora

Локальная игровая платформа для одиночных игр. Без подписки и регистрации.

## Запуск на Windows

Установите Node.js LTS, скачайте или клонируйте репозиторий. В папке проекта выполните:

```powershell
npm install
npm start
```

`npm test` запускает тесты ядра. `start.cmd` устанавливает зависимости при первом запуске.

Версия 0.1: каталог, обнаружение Steam, добавление EXE, запуск игр, избранное, история, резервное копирование папок сохранений. Трейнеры пока не подключены: функции на экране являются планом, отключены и не изменяют игру. Обложки загружаются из публичного CDN Steam; без сети есть заглушки. Nexora не связан со Steam или WeMod. Для собственного использования в одиночных играх.

## 0.2 · Mod discovery

Раздел «Моды» подключает публичный API Modrinth для Minecraft: поиск, фильтры версии и загрузчика, выбор релиза и JAR-файла. Файл сохраняется только после проверки размера и SHA-512; существующие файлы не перезаписываются. Загрузки сохраняются в локальной истории. Проверка целостности не является проверкой на вредоносный код. Установка, зависимости и обновления выполняются вручную. Никаких файлов модов Nexora не хостит. Для поиска необходим интернет.

См. [дорожную карту](docs/ROADMAP.md).

## 0.3 · Mod Manager

В «Загрузках» выберите «Установить», затем существующую папку `mods` нужного профиля Minecraft. Только JAR-файлы, ранее скачанные через Nexora и повторно проверенные по SHA-512; файлы не перезаписываются. В «Мои моды» можно отключать/включать установленные Nexora файлы и открывать папку. Отключение создаёт имя `.jar.nexora-disabled`, включение возвращает исходное. Для этого нужна файловая система с поддержкой жёстких ссылок (например, NTFS). Закройте игру, вручную проверьте загрузчик, версию и зависимости. Автоматическое разрешение конфликтов, установка зависимостей, сканирование чужих модов и обновление пока отсутствуют. SHA-512 не является антивирусной проверкой.

## 0.4 · Performance и сборка Windows

В разделе «Мониторинг» показываются фактические CPU, RAM и доступные данные GPU; история хранится в памяти окна. Датчики, которые драйвер не предоставляет, отображаются прочерком; FPS пока нет. Мониторинг использует локальную библиотеку, не собирает серийные номера и не отправляет данные на сервер.

Готовый Windows x64 пакет создаётся через `npm run package:win` (Node.js 22.12+; рекомендуется 24 LTS). В GitHub Actions после тестов формируется `Nexora-Windows-x64`. Распакуйте целиком и откройте `Nexora.exe`; Node.js для собранного приложения не нужен. Это неподписанная alpha-сборка, не установщик. Лицензии зависимостей сохраняются в пакете.
