# Nexora — Game Center

Цель: единый локальный центр игровой библиотеки, модификаций, сохранений и инструментов для одиночных игр.

## Реализация по этапам

- 0.2 Mod Discovery: Modrinth / Minecraft; поиск, совместимость, загрузки с проверкой целостности. Не автозагрузка зависимостей и не установка.
- 0.3 Mod Manager: адаптеры источников (Thunderstore, Nexus Mods через официальные разрешённые интерфейсы), профили, зависимости, конфликтующие файлы, откат и журнал установки. Оценить правила каждого источника.
- 0.4 Game Library: локальные игры Steam, Epic, GOG и Xbox при наличии поддерживаемого интерфейса; история сессий, пользовательские теги, избранное, запуск без изменения файлов.
- 0.5 Save Vault: версионирование и восстановление с подтверждением; резервное копирование настроек.
- 0.6 Trainer Engine: только поддерживаемые одиночные игры; локальные профили, версия игры, горячие клавиши, проверка совместимости, простой редактор значений, импорт доверенных форматов.
- 0.7 Performance / Overlay: FPS, CPU/GPU/RAM, время сессии, температура, заметки и быстрый доступ к настройкам без инъекций в защищённые игры.
- 0.8 Guides: гайды, ссылки на вики, заметки и чек-листы прохождения. AI-помощник опционально, с явным выбором провайдера.
- 0.9 Distribution: подписанный установщик, проверяемые обновления, локальные данные и разрешения, лицензии зависимостей и документация безопасности.

Версии ориентировочны. Не обходить античит, DRM, подписки сторонних сервисов или ограничения их API. Не исполнять скачанные файлы автоматически; отдельные действия установки должны иметь предварительный план и возможность отката.
