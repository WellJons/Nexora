# Nexora — первый пользовательский тест (0.24.1)

Цель: проверить реальное поведение Windows-приложения, не пытаться проверить все возможности за один запуск.

## Установка

1. Откройте в GitHub Actions последнюю **успешную** сборку требуемой версии.
2. В Artifacts скачайте **Nexora-Setup-Windows-x64** и распакуйте архив. Установщик пока не подписан цифровой подписью. Проверяйте источник и SHA-256; не отключайте защиту Windows ради установки.
3. Запустите мастер, установите приложение в отдельную папку, запустите Nexora.

## Основные сценарии

| Что проверить | Ожидаемый результат |
|---|---|
| Библиотека игр | Установленные игры обнаруживаются; ручное добавление EXE работает. |
| Кнопка Играть | Открывается обычный лаунчер/игра, Nexora показывает состояние поиска процесса. |
| Уже открытая игра | При обнаружении процесса второй экземпляр игры не запускается. |
| Трейнер | После загрузки сохранения одиночной игры без античита: открыть редактор, подтвердить подключение, найти изменяемое число, уточнить после изменения в самой игре; проверять запись только на отдельном тестовом сохранении. |
| Моды | На отдельном профиле Minecraft с подходящим загрузчиком или на игре с уже установленным BepInEx: установить доверенный совместимый мод, закрыть игру перед изменением, запустить правильный профиль, проверить работу и отключение. |
| Перевод | Установить Lite/Balanced, запустить игру без рамки, выбрать окно и проверить меню, инвентарь, диалоги. Затем сравнить с Advanced. |
| Мониторинг | Проверить доступные показатели и HUD; измерить FPS средствами самой игры до/после. |
| Сохранения | Сделать копию отдельной тестовой папки и извлечь в новую папку; сравнить файлы. |
| Интерфейс | Переключить разделы, изменить размер окна, проверить масштаб Windows и отключение анимаций. |
| Удаление | После теста закрыть приложение, удалить, оставив резервные копии; проверить сохранность модов и исходных файлов. |

## Что прислать при ошибке

Версия Nexora, название и магазин игры, версия Windows, точный порядок действий, текст ошибки, скриншот (без персональных данных). Для FPS — одинаковая сцена и настройки, значения до/после. Готовых проверенных игровых пресетов на этом этапе нет; персональные шаблоны не являются автоматически работающими читами.
